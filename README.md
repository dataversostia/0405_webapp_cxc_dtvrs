# Reporte de Cuentas por Cobrar — Dataversos

Dashboard de gestión de cartera de cuentas por cobrar: KPIs, antigüedad de saldos,
ranking de clientes, ficha de contacto por cliente, detalle filtrable y descarga en
PDF/Excel/CSV.

**Demo en vivo:** https://dataversostia.github.io/0405_webapp_cxc_dtvrs/

Los datos mostrados son ficticios (business case) y sirven solo como referencia visual.
